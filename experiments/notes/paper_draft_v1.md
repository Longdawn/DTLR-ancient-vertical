# UniVCP：面向古籍竖排文本的弱字符监督结构感知识别框架

## 摘要

即使文档图像已经被裁剪为单列或行级输入，古籍竖排中文文本识别仍然具有显著挑战。与常规横排文本识别相比，古籍竖排文本通常包含不规则字距、图像退化、大规模字符集变化以及高度不均衡的文本长度分布。另一方面，完整字符级框标注成本较高，现实中更常见的是少量字符级结构标注与较多行级转录标注并存。因此，关键问题不是如何依赖大规模字符框训练一个完整检测器，而是如何用有限字符级标注为行级识别模型提供可迁移的结构先验。本文提出 UniVCP，一个面向古籍竖排文本的弱字符监督结构感知识别框架。受 detection-based text line recognition 思路启发，UniVCP 并不将字符检测作为最终推理输出，而是仅使用少量字符框作为中间监督信号：首先通过查询式定位任务学习竖排列内的字符空间先验，然后通过分类头重建与字符映射初始化将该结构表征迁移到不同字符集的 CTC 识别任务，最后在推理阶段使用验证集选择的 blank/nonblank 校准以减少删除错误和空预测。

我们在 MTH1000、MTH1200、TKH、MTHv2-combo 和 HDRC 上进行实验。结果表明，所提出的预训练、迁移与校准流程能够在多个古籍文本域上保持稳定性能。在 MTHv2-combo 测试集上，UniVCP 达到 CER 3.90、AR 96.10、CR 96.37，优于同设置下多种 MMOCR CRNN/SVTR 基线；在 HDRC 上，UniVCP 达到 CER 9.30，并显著优于当前 MMOCR 对比结果。进一步的长度分桶分析表明，解码校准能够降低空预测率并改善短列鲁棒性，但极短文本仍然是主要错误来源。上述结果说明，显式结构预训练、字符集感知迁移和校准式 CTC 解码可以形成一种有效且可解释的古籍竖排文本识别方案。

## 1. 引言

文本行识别是 OCR 和手写文本识别中的基础任务。现代识别系统通常将其表述为序列预测问题：模型首先通过视觉主干提取图像特征，然后使用 CTC、循环网络或自回归 Transformer 将特征序列解码为字符序列。这一范式具有明显实践优势，因为它避免了显式字符分割，并且能够仅利用行级转录标注完成训练。然而，对于古籍竖排中文文本而言，纯序列建模隐藏了一个关键问题：字符不仅是转录序列中的 token，也是具有位置、尺度和局部排列关系的视觉实例。

本文关注单列或行级古籍竖排文本识别。本文不研究页面级版面分析、整页检测、文档解析或阅读顺序预测。输入被假设为已经裁剪好的竖排文本列或文本行图像，输出为对应的字符序列。即便在这一受限设定下，古籍文本识别仍然困难。真实古籍图像常包含断裂笔画、低对比度、墨迹扩散、稀有字符、异体字以及不一致的列几何形态。同时，不同古籍数据集往往具有长尾字符集和不同的字符覆盖范围，使得模型在跨数据集迁移时容易出现性能波动。

一种常见工程做法是将竖排列图像旋转后训练标准文本识别器。该策略是有效的，并且可以得到较强基线；我们的 MMOCR CRNN 和 SVTR 对比实验也验证了这一点。然而，旋转并不能完整解决古籍竖排文本识别问题。首先，旋转后的识别器仍主要依赖序列级监督，并未显式利用字符级竖排空间结构。其次，当下游字符集发生变化时，输出分类器必须重建，这往往导致训练初期不稳定。最后，CTC 识别器在短列样本上容易偏向 blank 预测；对于单字符样本而言，删除一个字符即可造成 100% 样本错误。因此，仅使用总体 CER 作为评估指标会掩盖严重的实际失败模式。

Detection-based text line recognition 提供了另一种视角。该类方法不直接按序列逐字符生成结果，而是并行检测所有字符，再将检测实例排序为转录结果。近期 DTLR 使用现代 Transformer 检测器重新审视这一较早的 OCR 范式，表明查询式检测模型可以同时定位大量字符，并且经过适当预训练后能够迁移到不同文字体系。其核心启发并不是必须用检测取代序列识别，而是说明字符定位监督能够提供序列级训练中缺失的显式结构学习信号。

本文将这一思想改造到古籍竖排文本识别中。我们的核心观点是：即使最终系统不输出检测结果，字符检测监督仍然有价值。具体而言，我们使用字符框监督预训练查询式模型，使其学习竖排列结构；随后将该结构感知表征迁移到 CTC 识别任务。这样，检测监督作为中间预训练任务存在，而不是作为部署阶段的两阶段检测-识别系统存在。这一区别使模型避免了测试时显式字符阈值筛选和排序，同时保留了字符级空间监督的优势。

我们将古籍竖排文本识别中的关键困难归纳为三类错配。

第一，结构错配。CTC 监督只观察转录序列，并不直接约束字符是否被正确定位。而在竖排文本中，模型需要在字距不均、字符退化和相似字形条件下稳定识别字符。字符级定位监督可以在识别微调前引导模型学习更可靠的空间对齐。

第二，类别错配。古籍数据集之间字符覆盖差异明显。一个在源字符集上预训练的模型通常无法直接复用其最终分类器到目标字符集。完全随机初始化分类器虽然简单，但会丢弃可复用字符知识，并可能破坏训练初期优化。因此，需要显式的分类头重建策略。

第三，解码错配。CTC 训练阶段边缘化所有可能对齐路径，而 greedy 推理阶段只选择单一路径并删除 blank。在实际识别中，这会导致 blank collapse、删除错误、空预测或预测过短。这些错误对短列样本尤其敏感，因为一次删除就可能主导样本错误。

为解决上述问题，本文提出 UniVCP。该框架由结构感知查询预训练、字符集感知分类头重建和验证集选择的 CTC 解码校准组成。UniVCP 的设计目标并不是引入更复杂的主干网络或外部语言模型，而是使训练、迁移和推理阶段都围绕古籍竖排文本的具体失败模式进行对齐。

本文贡献如下：

1. 将古籍竖排文本识别形式化为单列识别问题，并明确提出结构、类别和解码三类错配，为该任务提供了超越总体 CER 的诊断视角。
2. 将 detection-based text line recognition 改造为结构感知预训练阶段，利用字符框监督查询级定位，而最终识别仍采用 CTC 序列输出。
3. 使用分类头重建与字符映射初始化进行跨字符集迁移，降低随机替换分类器带来的训练不稳定性。
4. 使用验证集选择的 blank/nonblank 校准进行 CTC 解码，并通过 CER、AR、CR、空预测率、预测长度比例和长度分桶指标分析其影响。
5. 在 MTH1000、MTH1200、TKH、MTHv2-combo 和 HDRC 上进行实验，并在一致的单列识别设置下与 MMOCR CRNN/SVTR 基线进行比较。

## 2. 相关工作

### 2.1 文本行识别

文本行识别旨在将裁剪后的文本行图像转录为字符序列。早期 OCR 系统通常依赖显式字符分割，然后进行字符分类和序列建模。随着神经序列模型的发展，无分割识别逐渐成为主流。CTC 方法能够在不需要字符级标注的情况下对齐图像特征序列和文本标签，因此被广泛用于场景文本识别、印刷 OCR 和手写文本识别。CRNN 类模型通常结合卷积编码器和循环或序列解码器，近年来的识别器则进一步采用 Transformer 编码器或自回归解码器。

无分割识别的优势在于简单。识别器可以直接从图像-转录对训练，并在模型内部学习视觉证据与输出字符之间的对齐关系。然而，当视觉结构特殊或样本很短时，这种隐式对齐可能并不稳定。在古籍竖排文本中，字符位置和列结构提供了强先验，但标准 CTC 训练并不会显式监督这些先验。

### 2.2 基于检测的文本行识别

基于检测的识别方法将字符视为视觉实例。模型不直接预测字符序列，而是预测字符类别和位置，再将检测实例转换为有序转录结果。这一范式在早期 OCR 中较为重要，但在复杂手写文本中逐渐被无分割方法取代，主要原因是字符分割存在歧义，并且字符级标注成本较高。

现代 Transformer 检测器使该范式重新具有吸引力。DTLR 表明，DINO-DETR 风格架构能够并行检测文本行中的所有字符，并可在多种文字体系上微调。其主要洞察是，现代检测模型可以通过预训练学习近似字符定位，而这种定位能力可以支持跨字符集识别。

本文受这一思路启发，但目标和部署方式不同。我们并不将检测作为最终推理表示，而是使用检测监督预训练结构感知的视觉查询表征，然后进行 CTC 识别。该设计保持了简单的推理路径，同时保留了字符级空间监督带来的结构优势。

### 2.3 中文与历史文档识别

中文文本识别相比拉丁文字识别具有更大的字符集、更复杂的字形结构以及更强的类间视觉相似性。因此，中文手写文本识别常常受益于显式分割、弱监督字符定位或上下文建模。历史中文文档进一步带来图像退化、非标准字形、稀有字符、标注不一致以及馆藏风格差异等问题。

古籍竖排文本也不同于普通横排文本。字符自上而下排列，列宽可能狭窄或不规则，并且存在大量短列样本。虽然旋转图像可以使标准识别器适用，但旋转不会消除字符集变化和 CTC blank 偏置。因此，面向该场景的方法不应只报告总体 CER，还应报告短文本行为和空预测统计。

### 2.4 跨字符集迁移

在一个数据集上训练的识别模型通常不能直接复用其分类器到另一个数据集，因为字符集发生了变化。最简单的做法是使用随机初始化的新分类器替换旧分类器。这种做法安全但低效：已知字符会丢失原有分类权重，训练初期也可能产生不稳定梯度。DTLR 同样讨论了当目标 alphabet 不同于预训练 alphabet 时替换最终字符预测层的问题。

在古籍竖排文本中，字符集错配不是偶发现象，而是常态。MTH1000、MTH1200、TKH、MTHv2-combo、HDRC 以及新收集的数据集都可能具有不同的字符覆盖范围。因此，UniVCP 将分类头重建视为迁移流程中的核心步骤，而不是实现细节。

### 2.5 CTC 解码与校准

CTC 模型在每个时间步或查询位置上输出字符和 blank 的概率分布。Greedy decoding 删除重复 token 和 blank，而 beam search 或语言模型可以进一步改进结果。本文不使用外部语言模型，以保持比较聚焦于视觉识别能力。相反，我们采用简单的 logit 级校准：在 greedy decoding 前对 blank 和 nonblank logits 加上验证集选择的偏置。

该校准不是语言先验。它不改变字符之间的语言关系，也不注入外部语料统计。其作用是修正训练后识别器中系统性的 blank/nonblank 失衡。由于校准参数在验证集上选择并固定用于测试集，因此它可以作为透明的推理阶段组件进行评估。

## 3. 方法

### 3.1 问题定义

设 \(x\) 表示裁剪后的竖排文本列图像，\(y=(y_1,\ldots,y_T)\) 表示对应的真实转录序列，其中每个 \(y_t\) 属于数据集特定字符集 \(\mathcal{A}\)。目标是学习识别器 \(f_\theta\)，使其能够从 \(x\) 预测 \(y\)。在 stage-1 预训练中，部分数据集提供字符框 \(B=\{(b_i,c_i)\}_{i=1}^{N}\)，其中 \(b_i\) 表示字符边界框，\(c_i\) 表示字符类别。在下游识别阶段，模型使用行级转录进行训练和评估。

UniVCP 将学习过程分解为三个阶段：

1. 使用字符框进行结构感知查询预训练。
2. 针对目标字符集进行分类头重建。
3. 进行 CTC 微调并使用验证集选择解码校准参数。

测试阶段输出为字符序列。模型不预测页面级版面、阅读顺序或完整文档结构。

### 3.2 架构概述

模型采用本项目中的 DTLR/DINO 风格查询式架构。卷积主干首先提取多尺度视觉特征，Transformer encoder 对特征图进行进一步建模，Transformer decoder 输出一组查询表示。在定位预训练中，每个 query 预测字符类别和字符框。在 CTC 识别中，query 或序列表征被用于输出字符 logits，并通过 CTC loss 进行优化。

该架构适合古籍竖排文本识别，因为 query 可以并行表示候选字符位置。对于竖排文本列，decoder 能够建模相邻字符之间的交互，并抑制无关背景位置。与纯序列编码器相比，查询式形式天然支持预训练阶段的字符级定位监督。

### 3.3 结构感知查询预训练

在预训练阶段，模型使用字符级边界框和类别标签训练。给定 \(Q\) 个预测 query 和 \(N\) 个真实字符，Hungarian matching 将预测分配给真实字符实例或 blank/background 类。训练目标由分类损失和定位损失组成：

\[
\mathcal{L}_{stage1}
= \lambda_{cls}\mathcal{L}_{cls}
+ \lambda_{box}\mathcal{L}_{box}
+ \lambda_{giou}\mathcal{L}_{giou}.
\]

其中，分类项鼓励 query 识别字符或背景类别，box 项鼓励 query 响应与字符位置对齐。对于古籍竖排文本，该监督迫使模型在下游 CTC 训练前学习自上而下的字符组织方式、局部字距以及字符尺度。

本文的关键设计是：字符框预测分支被用作预训练信号，而不是最终推理输出。因此，该方法不同于完整的两阶段检测-识别系统。在识别阶段，我们仍依赖 CTC 解码，但视觉表征已经受到显式定位监督的约束。

当前可信主线使用 MTH1000+MTH1200 的字符框数据进行 stage-1 预训练。Full-MTHv2 stage-1 预训练和 query-budget continuation 被视为额外分支。初步诊断显示，full-MTHv2 预训练可能出现 nonblank query 过激活，而 query-budget 正则可以缓解该问题。这些分支目前作为预实验讨论，而不是最终结论。

### 3.4 分类头重建

设 \(\mathcal{A}_s\) 为预训练源字符集，\(\mathcal{A}_t\) 为下游目标字符集。当 \(\mathcal{A}_s \neq \mathcal{A}_t\) 时，分类器必须调整大小。朴素做法是随机初始化所有目标分类器权重。UniVCP 采用字符映射式重建策略。

对于每个 \(a \in \mathcal{A}_t \cap \mathcal{A}_s\) 的共享字符，我们从源分类头复制对应参数；对于源字符集中不存在的新字符，则使用默认初始化策略补齐。这样可以保留共享字符知识，同时允许模型表示新字符。

完成重建后，模型先进行分类头重建训练，再进行全模型微调。该阶段优化新分类器，同时避免突变梯度破坏预训练得到的结构表征。随后，全模型微调使模型适应目标数据集。

这一流程对古籍中文文本尤其重要，因为不同数据集之间既共享大量常见汉字，又包含稀有或馆藏特定字符。若将所有目标字符都视为全新类别，会丢弃大量可复用信息。

### 3.5 CTC 识别目标

在识别微调阶段，模型使用 CTC loss 训练。给定关于 \(\mathcal{A}_t \cup \{\varnothing\}\) 的 logits \(z\)，其中 \(\varnothing\) 表示 blank token，CTC 最大化所有可折叠到目标转录 \(y\) 的对齐路径概率：

\[
\mathcal{L}_{ctc} = -\log p(y|x).
\]

CTC 适合行级监督，因为下游数据不必提供字符框。然而，CTC 在训练阶段边缘化路径，在 greedy 推理阶段却选择单一路径，这会导致 blank/nonblank 平衡不理想。因此，我们进一步引入解码校准。

### 3.6 Blank/Nonblank 解码校准

推理时，我们在 greedy CTC decoding 前修改 logits：

\[
\tilde{z}_{t,\varnothing}=z_{t,\varnothing}+\beta_b,
\quad
\tilde{z}_{t,c}=z_{t,c}+\beta_{nb}, \ c\neq \varnothing.
\]

其中，\(\beta_b\) 为 blank bias，\(\beta_{nb}\) 为 nonblank bias。参数对 \((\beta_b,\beta_{nb})\) 在验证集上选择，并固定用于测试集。负 blank bias 和正 nonblank bias 可以减少删除和空预测错误，但过强校准可能增加插入。因此，校准必须同时通过 CER 和长度敏感指标评估。

本文分别报告 clean decoding 和 calibrated decoding。该区分是必要的，因为校准属于推理阶段组件，而不是重新训练得到的新模型。这样也可以直接度量 blank/nonblank 修正的影响。

### 3.7 Query Activation Budget 预实验正则

Full-MTHv2 定位预训练暴露出一种具体失败模式：模型预测的 nonblank query 数量远高于真实字符数。这种 nonblank over-activation 与 CTC blank collapse 是不同问题。在 MTH1000 验证集 box diagnostic 中，失败的 full-MTHv2 stage-1 分支平均 predicted nonblank count 约为 142.6，而真实平均长度约为 7.49；相同诊断协议下，可信的 MTH1000+MTH1200 stage-1 baseline 约为 40.79。

为研究这一失败模式，我们引入 length-aware query activation budget regularizer。该正则估计 nonblank query 的期望数量，并相对长度相关目标惩罚过量激活。初步结果显示，query-budget continuation 将 predicted nonblank count 降至约 43.11，接近可信 baseline。这说明 query 过激活是可测量、可约束的问题。

由于该分支的下游分类头重建和全模型微调仍在进行中，该正则目前尚不作为主结果使用。本文仅将其作为预实验和改进 full-MTHv2 预训练的候选方向。

## 4. 实验

### 4.1 数据集

本文在五个单列或行级古籍竖排文本设置上进行评估。

MTH1000 包含古籍竖排中文文本样本，并提供可用于 stage-1 和下游识别实验的字符级信息。MTH1200 是另一个相关子集，具有相近但不完全一致的字符分布。TKH 在当前实验中视觉难度相对较低，因此取得最强识别结果。MTHv2-combo 由 MTH1000、MTH1200 和 TKH 组合而成，用于评估跨子集统一训练能力。HDRC 是更困难的跨域数据集，包含更强退化和长列弱点。

本文所有实验均限制在裁剪后的单列或行级图像上，不评估页面级版面分析。

### 4.2 评估指标

本文报告 character error rate（CER）、accuracy rate（AR）和 correct rate（CR）。设 \(S\)、\(D\)、\(I\) 分别表示替换、删除和插入错误，\(N\) 表示真实字符数：

\[
CER = \frac{S+D+I}{N}, \quad
AR = 1 - \frac{S+D+I}{N}, \quad
CR = 1 - \frac{S+D}{N}.
\]

除总体指标外，本文还报告空预测率、预测长度/真实长度比例，以及 `len=1`、`len=2`、`len=3-5`、`len=6-10`、`len>=11` 的长度分桶 CER。这些指标是必要的，因为短列错误在总体 CER 中权重较低，但在实际使用中影响明显。

### 4.3 实现细节

主线 stage-1 模型使用 MTH1000+MTH1200 的真实竖排字符框数据进行预训练。下游识别使用 CTC 微调；当目标字符集不同于源字符集时，使用分类头重建。checkpoint selection 基于验证集 CER。解码校准参数在验证集上选择，并固定应用于测试集。

对于 MTHv2-combo 和 HDRC 对比实验，MMOCR 基线在导出的识别数据集上训练或评估。由于标准 MMOCR 识别器通常面向横排文本几何结构，因此我们在合适位置加入旋转版本。所有 MMOCR 指标均转换为与 UniVCP 一致的 micro CER/AR/CR 格式。

### 4.8 Stage-1 诊断与 MTHv2 预实验

本文使用 MTH1000 验证集上的 box diagnostic 评估 stage-1 定位质量。可信的 MTH1000+MTH1200 stage-1 baseline 平均 predicted nonblank count 约为 40.79。full-MTHv2 stage-1 分支产生约 142.6 个 predicted nonblank queries，表明存在严重 nonblank over-activation。query-budget continuation 将该值降至约 43.11，接近可信 baseline。

该诊断支持两个观察。第一，仅凭训练损失不足以判断 stage-1 质量。一个模型可能数值上稳定，却产生过多 nonblank query 激活。第二，nonblank over-activation 是具体且可正则化的失败模式。然而，良好的 box diagnostic 不自动等价于更好的最终识别性能。query-budget 分支仍需通过 MTHv2 分类头重建和全模型微调验证，才能被视为真正改进。

## 5. 讨论

### 5.1 为什么不在推理阶段使用检测输出

一个自然问题是：如果最终系统采用 CTC，为什么字符检测监督仍然有帮助？原因在于，检测和识别不必共享相同输出形式。检测监督在预训练阶段提供显式空间学习信号。当模型已经学习字符通常出现的位置以及竖排列内的组织方式后，CTC 微调可以直接利用这种表征，而无需在测试阶段输出字符框。

这类似于使用辅助任务进行表征学习。辅助任务之所以有价值，是因为它暴露了主监督中缺失的结构信息。本文中，行级转录没有告诉模型每个字符位于何处，而字符框提供了这一信息。因此，预训练阶段使用字符框塑造模型，再由下游识别阶段完成转录预测。

### 5.2 为什么旋转不是完整基线

MMOCR 结果表明，旋转后的识别器已经较强。因此，本文不能将贡献表述为“普通模型无法处理竖排方向”。更合理的表述是：旋转处理了图像方向层面的几何问题，而 UniVCP 进一步处理结构监督、字符集迁移和 CTC 解码偏置。即使图像方向被校正，这些问题仍然存在。

### 5.3 短列识别仍然是开放问题

当前最稳定的弱点是短列识别。对于 `len=1` 和 `len=2`，模型几乎没有上下文可用于纠正视觉歧义。解码校准能够减少 blank 导致的删除，但不能凭空产生缺失视觉证据，也不能完全解决稀有字符歧义。未来工作可以考虑短列感知训练目标、置信度驱动校准或针对极短样本的辅助监督。

### 5.4 当前研究边界

本文不解决页面级版面解析、阅读顺序预测或文档级识别，也不使用外部语言模型。这些限制使实验比较更清晰，但也限定了方法适用范围。此外，部分有潜力的分支，尤其是带 query-budget 正则的 full-MTHv2 预训练，目前仍处于预实验阶段。在下游识别结果完成前，它们应被视为未来消融，而不是主结论。

## 6. 结论

本文提出 UniVCP，一个面向古籍竖排文本识别的结构感知查询预训练框架。该方法使用字符定位监督学习竖排列结构，通过分类头重建完成跨字符集迁移，并在推理阶段使用验证集选择的 CTC blank/nonblank 校准。MTH1000、MTH1200、TKH、MTHv2-combo 和 HDRC 上的实验表明，该方法在多个古籍竖排文本域中具有稳定识别性能，并在 MTHv2-combo 和 HDRC 上优于当前 MMOCR 基线。进一步诊断显示，空预测、短列错误和 nonblank query 过激活是不同失败模式，应分别评估。

当前结果支持将检测式监督转化为 CTC 识别可迁移结构先验的有效性。后续工作将完成 full-MTHv2/query-budget 下游评估，扩展分类头重建消融，并针对短列识别设计更专门的优化方法。
