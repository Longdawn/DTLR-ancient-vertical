# 6. 结论

本文提出 SAQT，一个面向古籍竖排单列文本识别的结构感知查询学习方法。该方法将字符框监督用于字符定位信息学习，而非作为最终推理输出；当目标字符表发生变化时，字符表感知分类器适配模块继承共享字符参数，并为新增字符构造初始化；随后，模型通过 CTC 识别训练完成行级转录建模，并在推理阶段采用轻量级 blank/nonblank 校准调整 CTC 解码倾向。

在 MTHv2 和 HDRC 上的结果显示，SAQT 相比本文比较的多种竖排适配场景文本识别基线取得更高的 AR/CR。进一步的 HDRC 随机分类头对照显示，字符表感知初始化优于随机目标分类头初始化；MTHv2 上的 query budget 消融为长度感知查询约束提供了内部证据；分类头重建与全模型训练对照说明，仅更新输出分类器不足以充分适配识别任务。MTHv2 上的 expected-count 辅助项带来小幅提升，但 HDRC 上未形成稳定收益，因此本文将其作为轻量可选模块而非普适核心。无字符定位学习的 CTC 对照则说明，在当前查询式架构和训练预算下，仅依赖行级转录难以形成可用的 query-to-sequence 表示。解码校准能够改善识别指标，但其作用限于 blank/nonblank 全局偏置调整，不能替代针对字符混淆和图像退化的建模改进。未来工作将进一步研究更强的字符表适配策略，以及不依赖大量字符框标注的字符定位信息学习方式。
