# SAQT：面向古籍竖排文本识别的结构感知查询学习方法

## 摘要

中文古籍竖排文本识别是历史文献数字化中的基础环节。与常规场景文本或现代印刷文本相比，古籍图像往往同时受到纸张退化、墨迹扩散、低对比度和历史字形变化的影响；其字符沿竖直方向排列，字距和局部结构并不稳定，不同馆藏或数据集之间还存在明显的字符表差异。现有无分割识别器主要依赖行级转录监督，能够避免显式字符切分，却难以直接利用字符在列内的空间组织；检测式识别虽然能够建模字符位置，但若在推理阶段依赖检测框筛选和排序，则容易引入额外的后处理误差。

本文提出 SAQT，一个面向古籍竖排文本识别的结构感知查询学习方法。SAQT 将检测式查询作为字符定位信息与行级序列识别之间的中间表示，而非作为最终检测输出：在字符定位信息学习阶段，字符框监督促使查询学习字符级视觉证据、字符位置及其竖排空间组织；在识别阶段，模型依据竖直位置对查询进行排序，并将其转换为 CTC 序列，通过行级转录完成训练。针对古籍数据集之间常见的字符表差异，SAQT 进一步引入字符表感知分类器适配策略，继承共享字符的分类参数，并为新增字符构造参数初始化。在 MTHv2 和 HDRC 两个古籍竖排文本数据集上的实验中，SAQT 的 AR/CR 高于本文纳入比较的竖排适配场景文本识别基线；在开发集固定的解码协议下，分别达到 96.75/97.00 和 93.44/94.36。
